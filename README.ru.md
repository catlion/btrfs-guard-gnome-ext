# Btrfs Guard — расширение GNOME Shell

Индикатор на панели, который следит за **нераспределённым пространством** файловых систем btrfs и помогает его освободить до того, как записи начнут зависать.

## Как это работает

btrfs не возвращает место в «нераспределённое» при удалении файлов. Пространство выделяется фиксированными по размеру **чанками** (обычно 1 GiB для данных и 256 MiB для метаданных). Когда нераспределённое пространство заканчивается, btrfs не может выделить новые чанки — метаданные больше не могут расти, и записи зависают, хотя `df` может по-прежнему показывать нормальные значения. В такой ситуации восстанавливаться тяжело.

Btrfs Guard постоянно отслеживает нераспределённое пространство и предлагает балансировку одним щелчком:

1. **Наблюдение** — для каждой настроенной точки монтирования расширение:
   - определяет UUID btrfs и базовое устройство один раз (через `findmnt`), затем
   - считывает счётчики выделения из sysfs (`/sys/fs/btrfs/<uuid>/allocation/*`) и размер устройства из `/sys/class/block/<dev>/size` — без вызовов CLI `btrfs` и без прав root, поэтому опрос каждые 30 с практически ничего не стоит.
   - *Нераспределённое = размер устройства − Σ disk_total чанков data/metadata/system.*
2. **Оповещение** — когда нераспределённое пространство опускается ниже **1 GiB**, метка на панели становится красной со значком предупреждения, и выводится **критическое** уведомление; повторное оповещение не чаще, чем раз в 30 минут, пока место не будет освобождено.
3. **Освобождение** — меню запускает `pkexec btrfs balance start -dusage=N <mount>`:
   - `-dusage=0` удаляет полностью пустые чанки,
   - `-dusage=N` (по умолчанию **60**, настраивается) уплотняет частично заполненные чанки, и их свободное место возвращается в пул нераспределённого.
   Балансировка требует порог использования чанков — меньшие значения безопасны, но дают меньше эффекта; большие значения освобождают больше, но переписывают больше данных.
4. **Просмотр** — пункт меню показывает `btrfs filesystem usage` для точки монтирования в прокручиваемом диалоге.

## Настройки

Открываются через приложение *Extensions* → Btrfs Guard → значок шестерёнки (или `gnome-extensions prefs btrfs-guard@ak0.org`):

- **Отслеживаемые разделы** — список точек монтирования btrfs; для каждой — отдельный индикатор на панели. Можно добавить вручную или нажать *Detect btrfs mounts*, чтобы автоматически добавить все файловые системы btrfs из `findmnt` (одна точка монтирования на файловую систему; устаревшие точки без UUID пропускаются).
- **Порог использования чанков** — `N` в `balance -dusage=N` (0–100 %, по умолчанию 60).

Настройки хранятся в GSettings по пути `org.gnome.shell.extensions.btrfs-guard`.

## Переводы

Строки, видимые пользователю, помечены для gettext (домен `btrfs-guard`). Русский (`ru`) уже поставляется; чтобы добавить язык, создайте `po/<lang>.po` из `po/btrfs-guard.pot` (обновить его можно командой `xgettext --from-code=UTF-8 --keyword=_ -o po/btrfs-guard.pot extension.js prefs.js`), переведите файл, затем соберите и установите:

```sh
mkdir -p locale/<lang>/LC_MESSAGES
msgfmt po/<lang>.po -o locale/<lang>/LC_MESSAGES/btrfs-guard.mo
```

## Установка из исходников

```sh
git clone https://github.com/catlion/btrfs-guard-gnome-ext.git
cd btrfs-guard-gnome-ext
glib-compile-schemas schemas
cp -r . ~/.local/share/gnome-shell/extensions/btrfs-guard@ak0.org
# выйдите из сеанса или перезапустите GNOME Shell, чтобы загрузить расширение
```

## Требования

- GNOME Shell 48 или новее
- btrfs-progs (`/usr/bin/btrfs`) и polkit (`pkexec`) — используются только для действий balance/usage
